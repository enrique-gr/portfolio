Incident & Resolution Log // Anomalies

03
  • Resolved

    INCIDENT #VTOL-01

    Sensor Dropouts on Bench Test

    Root Cause
    Electrical noise from high-current motor wiring interfering with I2C lines.
    The Fix
    Re-routed and shielded avionics wiring; added pull-up resistors.
  • Resolved

    INCIDENT #HYPERION-01

    Thread Contention Jitter

    Root Cause
    Physics and telemetry threads competing for mutex, delaying integration steps.
    The Fix
    Implemented double-buffered state handoff to eliminate blocking.
  • Resolved

    INCIDENT #PROP-09

    Igniter Continuity False Positive

    Root Cause
    ADC float voltage on the sense pin was interpreted as a valid continuity high.
    The Fix
    Added hardware pulldown resistor and debounce logic to MCU firmware.
  • Resolved

    INCIDENT #DBF-01

    Pitch Stability Hunting

    Root Cause
    CG shifted aft due to battery placement, reducing static margin.
    The Fix
    Shifted mass forward and increased tail authority.
